# blender_wing_generator
[Ai assisted] blender 5.2参数化鸟翼制作插件，参考真实鸟翼结构，可自定义羽毛长度、位置、形态等参数。可预览拍翼动画和生成简单绑骨模型。A parametric bird-wing modeling add-on for Blender 5.2, based on real bird wing anatomy, with customizable feather length, position, shape, and other parameters. It supports flapping animation previews and the generation of simple rigged models.
