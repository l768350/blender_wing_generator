# Blender Wing Generator: Wing Model
简体中文 | [English](README_EN.md)

这是一个由 AI 辅助编写代码的 Blender 程序化鸟翼制作插件，设计参考真实鸟翼结构。你可以自定义羽毛的长度、位置、形态及分组参数，预览拍翼动作，并生成带有基础绑定的鸟翼模型。
## 功能特点
- 参数化鸟翼生成：可调整翼展、翼面纵深、宽度、后掠、扇开、翼尖圆钝度、羽毛间隙和翼尖抬升等参数。
- 羽毛分组：包含初级飞羽、次级飞羽、三级飞羽、初级覆羽、大覆羽、中覆羽、小覆羽、腋羽和小翼羽。
- 分组与单根羽毛参数：可设置羽毛数量、尺寸、偏移量和长度分布曲线等参数。
- 翼型预设：包括原始鸽翼、椭圆翼、尖窄高速翼、长窄滑翔翼和升腾滑翔翼等预设。
- 动作预览工具：预览拍翼运动，并辅助寻找较为展开的翅膀姿态。
- 基础绑定工作流：提供主翼骨链、羽毛骨骼、网格蒙皮、约束、姿态控制、收展控制和循环控制等工具。
- 辅助工具：包括参数 JSON 导入、UV 工具、姿态重置和绑定诊断等功能。
## 环境要求
- Blender 5.2
- 插件当前源码的导入项不要求额外安装第三方 Python 包。
## 安装方法
1. 下载插件的 .zip 压缩包，不要解压。
2. 将 .zip 文件直接拖入 Blender 窗口。
3. 如果没有自动开始安装，可在 Blender 中打开 编辑（Edit）→ 偏好设置（Preferences）→ 插件（Add-ons），从右上角菜单选择 从磁盘安装（Install from Disk），然后选择该 .zip 文件。
4. 启用 Wing Model 插件（如果安装后尚未自动启用）。
5. 在 3D 视图中按 N 打开侧栏，找到 Wing Model 面板。
## 基本使用
1. 在 3D 视图侧栏打开 Wing Model 面板。
2. 选择一个翼型预设，或手动调整整体形态参数。
3. 设置各组羽毛数量，并根据需要调整全局、分组或单根羽毛参数。
4. 使用面板中的模型创建工具生成或重新生成模型。
5. 使用动作工具预览拍翼运动。
6. 需要绑定时，使用相应的绑定工具生成主翼骨链、羽毛骨骼并执行蒙皮；必要时运行绑定诊断工具进行检查。
不同版本中的控件名称和具体功能可能有所变化。在重新生成模型或尝试绑定功能前，建议先备份 .blend 文件。
## 项目状态
本项目仍在开发中。插件包含程序化建模与绑定工作流，但生成的绑定仍需要针对具体模型进行测试和调整。目前目标版本为 Blender 5.2，尚不保证兼容其他版本。
